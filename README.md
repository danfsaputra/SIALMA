# Si Alma Pemerintah Kabupaten Bojonegoro

Dinas Perpustakaan dan Kearsipan Kabupaten Bojonegoro

## Requirements

Laravel ^10

VueJs 3 with Inertia

Php ^8.2

Node ^20.0.0

## Project Setup

composer install

php artisan migrate

npm install

## Run Project

npm run dev

## Database

MySQL

## .env Setting (Example)

SANCTUM_STATEFUL_DOMAINS=localhost,kearsipan.id
